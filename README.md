# CHAOS;CHILD らぶchu☆chu!!(스위치판) 한국어 번역 작업물

「CHAOS;CHILD らぶchu☆chu!!」(카오스 차일드 LCC) 닌텐도 스위치판의 일본어 시나리오를 한국어로 옮기는 작업물이다.
번역 킷(원문 묶음·지침·용어집·인물 말투·검사기)과, 클라우드 세션 4개가 갈래별로 번역한 결과를 담는다.
게임에 넣는 도구(추출·삽입·글꼴 처리)와 패치 파일은 이 저장소에 없다. 아직 게임에 넣을 수 있는 패치가 아니다.

작업 방법은 [`CLAUDE.md`](CLAUDE.md)와 `cclcc-ko-kit/00_먼저_읽기.md`에 있다.

## 추가·변경 사항

원판(일본어 스위치판, 공식 한국어 없음) 대비 이 작업물이 더한 것을 정리했다.
괄호 안은 근거가 된 커밋·파일·브랜치다. 확실하지 않은 것은 「(추정)」으로 표시했다.

### 번역 범위

- **번역 원문**: 스위치판 일본어 대본에서 뽑은 원문 묶음 344개, 27,736항목이다. 대사 19,513, 지문 6,843(주인공 미야시로 타쿠루의 1인칭 서술), TIPS 용어 해설 1,011, 시스템 문자열 369(메뉴·확인 창·장 제목·해금 알림) (`cclcc-ko-kit/원문/`).
- **번역 기준**: 일본어 원문만 쓴다. 공식 한국어판·팬 번역·영어판은 참고하지 않는다. 다만 인물 이름의 읽기는 대본 루비·음성 부호와 함께 스팀 영문판 로마자 표기를 근거로 확인했다 (`cclcc-ko-kit/00_먼저_읽기.md` 2절, `02_용어집.md`).

### 번역 규칙(킷에 정한 것)

- **문장**: 「일본어 원문의 뜻을 보전하되, 한국인이 읽기에 자연스러운 문장으로」. 어순·문형은 바꿔도 되고, 원문에 없는 사실·감정·꾸밈은 더하지 않는다. 대사는 입말로 쓰고, 대사에 「그/그녀」를 쓰지 않는다 (`00_먼저_읽기.md` 1절).
- **태그**: 줄바꿈 `⟦n⟧`, 글자색 `⟦col:…⟧`, 루비 `⟦rb⟧…⟦rt⟧…⟦/r⟧`, 배치 제어(`⟦top:N⟧`, `⟦size:N⟧` 등), 기호 `⟦g:번호⟧`를 원문과 같은 개수·순서로 둔다. 한자 읽기만 돕는 루비는 한 벌을 통째로 빼고, 말장난 루비(예: 염동력/능력, 아오바 기숙사/우리 집, 현실화/리얼 부트)와 강조점 루비는 살린다 (`01_번역지침.md` 2·3절).
- **글자**: 가나·한자를 남기지 않는다. 문장부호는 반각, 줄표는 「――」만, 말줄임표는 「……」, 전각 영숫자는 반각, `ｗｗｗ`는 「ㅋㅋㅋ」. 스위치판 글꼴에 없는 글자(ASCII `"`, `♡` 등)는 쓰지 않는다 (`01_번역지침.md` 4절, `tools/font_chars.json`).
- **말투**: 원문 줄이 です·ます면 존댓말, 아니면 반말. 1인칭은 모두 「나」(존댓말이면 「저」), 2인칭은 대개 「너」, 「자네」는 쓰지 않는다. 인물 16명과 그 밖의 인물의 말투·부르는 말·말버릇, 한 인물이 다른 모습으로 나오는 장면의 구분을 03 문서(보강 2판)에 정했다 (`03_캐릭터보이스.md`).
- **이름·용어**: 인물 이름(예: 宮代拓留=미야시로 타쿠루, 香月華=카즈키 하나, 神成岳志=신조 타케시), 호칭, 작품 용어를 02 용어집 확정 1판대로 쓴다 (`02_용어집.md`, `tools/glossary.json`).
- **자주 틀리는 것**: お帰り=「어서 와」, 1인칭 지문의 피동 풀기, 「、」를 쉼표로 그대로 옮기지 않기, 한자음 함정(奇遇≠기우, 唐突≠당돌, 本命≠본명 등) (`00_먼저_읽기.md` 6절).

### 검사기 (`tools/gates.py`)

묶음마다 원문과 번역을 맞대어 본다. 오류: 항목 수·id 순서 어긋남, 빈 번역(보류 꼴은 통과), 실제 줄바꿈 문자, 태그 개수·순서, 루비 꼴, 강조점 수, 가나·한자 잔류, 전각 부호, 잘못된 줄표, 글꼴에 없는 글자, 대사 속 「그녀」, 원문은 존댓말인데 번역은 반말인 줄이 많은 경우, 긴 본문 줄의 복사 채우기. 참고(경고): 화자 이름을 번역문 앞에 넣었는지, 대사 속 3인칭, 원문보다 훨씬 긴 줄, 일본어 쉼표 끊김을 옮긴 꼴, 밑글과 같은 루비.

### 알려진 문제

- **보류 재검토를 아직 안 했다.** 네 갈래 번역은 보류 기준을 좁히기(`442cf6b`) 전에 끝났고, 어느 브랜치에도 「보류 재검토」 커밋이 없다. 새 기준으로는 번역해야 할 연애·농담 줄이 3,017줄 안에 많이 들어 있을 것이다 (`CLAUDE.md` 4절) (추정).
- 번역 결과가 `main`에 합쳐지지 않았다. 네 브랜치는 `df53f68` 위에 있어 좁힌 보류 기준 문서도 받지 않은 상태다.
- 사람이 원문과 대조한 의미 검수는 기록이 없다. 검사기는 형식만 본다.
- 갈래 사이의 부르는 말·말투 통일은 03 문서로 맞추도록 했을 뿐, 갈래끼리 맞대어 본 기록은 없다.
- 게임에 넣는 도구(대본 추출·삽입, 한글 글꼴)가 없다. 스위치판에 넣을 방법과 화면 폭(줄 넘침)은 아직 정해지지 않았다.
- `00_먼저_읽기.md` 3절 제목은 「이번 번역은 Gemini가 한다」로 남아 있지만, 본문과 `CLAUDE.md`는 Claude 클라우드 세션이 번역한다고 적고 있다. 킷을 처음 제미나이용으로 만든 흔적이다.
